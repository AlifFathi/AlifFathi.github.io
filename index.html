About Me

A bit about my background and academic journey

I am currently pursuing a Bachelor of Computer Science (Data Engineering) at Universiti Teknologi Malaysia (UTM). Over six semesters I have built a broad foundation — programming in C++, Java, and Python; designing relational and NoSQL databases; and working hands-on with networking, operating systems, software engineering, and enterprise systems.

My focus has increasingly shifted toward data engineering: data mining and clustering, high-performance data processing with Apache Spark, cloud services on Microsoft Azure, business intelligence pipelines, and applied AI. I enjoy turning raw data into insight and building systems that solve real problems, and I thrive in collaborative, project-based environments.

Reflections

What I've learnt and how I've grown across each subject of my degree

Semester 1

Programming Technique I

C++ Fundamentals

This was my first real exposure to programming. I learned the building blocks of C++ — variables, control flow, functions, and arrays — and discovered how to break a problem down into logical steps and translate it into working code.

Improvement: I'd practise more on algorithm efficiency rather than just getting the correct output.
Discrete Structure

Mathematical Foundations

This course gave me the mathematical reasoning behind computing — logic, set theory, relations, functions, and combinatorics. It trained me to think formally and proved how essential maths is to computer science.

Improvement: I'd connect each concept to a concrete coding example to make the theory stick better.
Digital Logic

Logic Gates & Circuits

I learned how computers work at the hardware level — Boolean algebra, logic gates, and combinational and sequential circuits. Designing circuits for the project showed me the foundation beneath every program I write.

Improvement: I'd simulate more complex circuits to better appreciate real processor design.
Technology & Information System

IS & Design Thinking

This course introduced the role of information systems in organisations and the design-thinking process. Building a low-fidelity prototype taught me to focus on user needs before jumping into a solution.

Improvement: I'd gather real user feedback to validate the prototype rather than relying on assumptions.

Semester 2

Programming Technique II

Object-Oriented C++

Building a full C++ game from scratch is where object-oriented programming finally clicked. Splitting the game into classes for enemies, loot, and game states taught me encapsulation and how to manage a larger codebase.

Improvement: I'd apply design patterns to make the code cleaner and easier to extend.
Computer Organization & Architecture

CPU & Memory Design

This course revealed what happens inside the machine — CPU design, memory hierarchy, and instruction execution. It deepened my understanding of why certain code runs faster than others.

Improvement: I'd relate architecture concepts directly to performance tuning in my own programs.
Human Computer Interaction

Usability & UX Design

The project taught me to design for people, not just functionality. I learned usability principles, user-centred design, and how to evaluate an interface from the user's perspective.

Improvement: I'd run formal usability testing with real users to back up design decisions.
Probability & Statistical Data Analysis

Applied Statistics

This course built my statistical foundation — probability, distributions, and hypothesis testing. Applying statistics to a real dataset in the project showed me how data turns into evidence-based conclusions.

Improvement: I'd use a statistical tool like R or Python to analyse larger, messier datasets.
System Analysis & Design (WBL)

Requirements & Modelling

I learned the full process of analysing a system before building it — gathering requirements, UML modelling, and writing an IEEE-format report. The industry talk connected classroom theory to real-world practice.

Improvement: I'd involve stakeholders earlier to refine requirements more accurately.

Semester 3

System Development Technology

Full-Stack Web Development

Building the Course Registration System and the cooperative management system taught me end-to-end full-stack development — PHP, MySQL, role-based authentication, and teamwork on real requirements. It was my first taste of production-style software.

Improvement: I'd use an MVC framework like Laravel instead of procedural PHP for maintainability.

Improvement: I'd explore dynamic routing protocols and network security in more depth.
Data Structure & Algorithm

C++ Data Structures

Implementing linked lists, sorting, and a flight-simulation mini project in C++ sharpened my problem-solving and taught me to choose the right data structure for the job, balancing time and space.

Improvement: I'd analyse the time complexity of each solution more rigorously.

Improvement: I'd apply Agile practices on a real team project to experience them firsthand.
